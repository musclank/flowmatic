# FLOWMATIC

**Connect. Automate. Grow.**

FLOWMATIC is a visual workflow automation platform. Build workflows by connecting triggers, actions, conditions, and integrations in a visual canvas.

## Planned foundation
- React + TypeScript + Vite
- Tailwind CSS
- React Flow visual workflow builder
- Cloudflare Pages frontend
- Cloudflare Workers API and execution services
- Supabase Auth and PostgreSQL

## Status
Project repository initialized. Application foundation is being built.

## Development
Install dependencies with `npm install`, then run `npm run dev` once the application source is added.

Never commit API keys, access tokens, or other secrets.
